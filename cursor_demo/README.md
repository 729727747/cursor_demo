# 智能聊天应用

一个现代化的Web聊天应用，集成了AI助手、实时对话、文件分享等功能。界面简洁直观，支持多种消息类型和个性化设置。

## 🌟 主要特性

### 💬 聊天功能
- AI助手智能对话
- 实时消息发送和接收
- 聊天记录本地持久化
- 消息搜索和高亮显示
- 支持多种消息类型：文本、图片、文件、语音

### 🤖 AI助手
- 集成Deepseek AI接口
- 智能对话和上下文理解
- 支持Markdown格式
- 代码块高亮显示
- 自动保存对话历史

### 📁 文件处理
- 图片上传和预览
- 多文件格式支持
- 文件大小显示
- 自定义文件图标
- 图片点击放大

### 🎤 语音功能
- 语音消息录制
- 实时录音动画
- 音频播放控制
- 录音权限管理

### ⚙️ 个性化设置
- 用户头像自定义
- 用户名修改
- 深色/浅色主题
- 通知管理
- 声音提醒
